# odin-recipes
The Odin Project tutorial implementation

This is the first assigment in TOD where I will use Git. The goal here is to practice all of the HTML knowledge I have acquired in previus lessons. In this project, I'm going to build a basic recipe website.

The website will consist of a main index page which will have links to a few recipes. The website won’t look very pretty by the time we have finished but it’s important to keep in mind that the purpose of this project is to build your HTML chops; we will revisit this project in the future to style it up with CSS.

By the end of the current project I would like to demonstrate that I have a beginner level basic understanding of HTML and that I can wield Git confidently.
